# Abhinav MERN Portfolio

## Features
- React + Vite frontend
- Express + MongoDB backend
- Working contact API
- Project API with featured filtering
- Dark/light theme
- Command palette (Ctrl/Cmd + K)
- Admin dashboard for messages and projects
- Responsive UI, animations, SEO metadata

## Run
1. Copy `server/.env.example` to `server/.env`
2. Add your MongoDB URI and admin key
3. `cd server && npm install && npm run dev`
4. `cd client && npm install && npm run dev`

Client: http://localhost:5173
Server: http://localhost:5000
